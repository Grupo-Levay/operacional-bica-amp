# S7.0 Phase 2 — Design System v3 — Modernização Visual

**Estado:** todo
**Modo:** Standard
**Duração estimada:** 3-4 dias
**Origem:** Plano XOIA Framework Phase 2 (Cleanup S5.0 + Redesign UI)

## Description

Modernização visual do design system: evolução de tokens (paleta, tipografia, sombras, gradientes), redesign de componentes base (button, card, input, badge, progress-ring, level-bar), criação de guia visual e aplicação consistente em todo o codebase.

**Objetivo:** Base visual moderna e coerente para Phase 3 (redesign de 5 pages críticas).

## Acceptance Criteria

- [ ] Audit visual completo documentado (AUDIT-VISUAL.md)
- [ ] Paleta v3 definida e validada (Bica #C9A368, AMP #B91C1C, sombras dinâmicas, gradientes)
- [ ] Tipografia com escalas completas (xs, sm, base, lg, xl, 2xl, 3xl)
- [ ] Componentes base redesenhados (button, card, input, badge, progress-ring, level-bar)
- [ ] DESIGN-v3.md criado (princípios, padrões, exemplos de uso)
- [ ] Tokens aplicados em components/ui/ + components/shared/
- [ ] npm lint + npm typecheck + npm test = GREEN
- [ ] PR criada (draft) em claude/trusting-cannon-LoCBL

## Tasks

### 1. Audit Visual Completo
- [ ] Capturar screenshots estado atual (desktop 1440px, tablet 768px, mobile 390px)
- [ ] Comparar com padrões modernos (2026): Figma, Dribbble, design patterns atuais
- [ ] Identificar gaps: tipografia, cores, spacing, componentes
- [ ] Documentar em AUDIT-VISUAL.md (findings + recommendations)

### 2. Design Tokens v3 — Paleta & Tipografia
- [ ] Revisar paleta: Bica #C9A368 ainda funciona? AMP #B91C1C adequado?
- [ ] Adicionar sombras dinâmicas, gradientes, efeitos de profundidade
- [ ] Criar escalas de tipografia: xs, sm, base, lg, xl, 2xl, 3xl
- [ ] Refinar escala de spacing (validar aplicação existente)
- [ ] Adicionar variantes de border-radius por componente
- [ ] Update: `src/tokens/tokens.yaml` + `src/app/globals.css`

### 3. Redesign Componentes Base
- [ ] `button.tsx` — adicionar variantes (ghost, outline, gradient)
- [ ] `card.tsx` — melhorar sombra, border-radius, padding
- [ ] Input components — affordances melhoradas (focus states, labels)
- [ ] Badge + status pill — cores semânticas atualizadas
- [ ] Progress ring + level bar — cores e animações refloradas
- [ ] Aplicar tokens em tudo (não hardcoded colors)

### 4. Guia Visual v3
- [ ] Criar DESIGN-v3.md com:
  - Princípios de UI (consistency, affordance, contrast)
  - Padrões de uso (quando usar card vs list, badge vs pill)
  - Exemplos de componentes em contextos reais
  - Checklist accessibility (WCAG AAA)

### 5. Aplicar Tokens em Codebase
- [ ] Passar por `components/ui/*.tsx` — remover hardcoded colors
- [ ] Passar por `components/shared/*.tsx` — aplicar tokens
- [ ] Exemplo: `bg-bica` → `bg-primary`, `text-amber-600` → `text-primary-fg`
- [ ] Validar contrast em todos os estados (light/dark se aplicável)

### 6. Quality Checks
- [ ] npm lint = GREEN
- [ ] npm typecheck = GREEN
- [ ] npm test = GREEN

## Notas
