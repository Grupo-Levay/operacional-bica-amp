# S8.0 — Performance & Observability (Self-Hosted)

**Estado:** doing
**Modo:** Deep (incremental por fases)
**Origem:** Pedido do usuário — instrumentar a operação sem dependência externa (zero SaaS)

## Description
Dar olhos à operação BiCA/AMP sem trazer SaaS. Tudo self-hosted no Supabase:
captura de eventos de uso, rastreamento de erros persistido, baseline de
performance (Web Vitals reais + Lighthouse) e painel de saúde no admin.

## Decisões de modelo (aprovadas)
- **Sem SaaS:** zero Sentry, zero PostHog. Lighthouse CI + bundle-analyzer (open-source) OK.
- **Uma tabela:** `analytics_events` cobre eventos, erros e web vitals (via `status`/`value`/`error_message`).
- **Wrapper:** `withAnalytics()` instrumenta Server Actions sem refactor (captura duração + erro).
- **Entrega:** Fases 1–3. Fase 4 (analytics de produto/dashboards) é follow-up S9+.
