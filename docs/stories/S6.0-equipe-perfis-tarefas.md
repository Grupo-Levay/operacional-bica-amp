# S6.0 — Equipe: Perfis, Gestão e Distribuição de Tarefas

**Estado:** doing
**Modo:** Deep (incremental por fases)
**Origem:** Pedido do usuário (gestão de equipe + perfil individual + Kanban de tarefas + metas)

## Description
Ambiente completo de equipe: cada usuário vê seu perfil (função, responsabilidades,
escala, tarefas, metas, evolução) e admins/super_admins gerenciam a equipe como um
todo, com distribuição de tarefas (Kanban) e metas individuais/de equipe.

## Decisões de modelo (aprovadas)
- **Vínculo:** `equipe.perfil_id` liga conta ↔ membro da escala (1:1 por casa)
- **Tarefas:** nova tabela `tarefas` + Kanban (admin distribui a fazer/fazendo/concluída)
- **Metas:** nova tabela `metas` numéricas (admin define por pessoa/equipe) + evolução no tempo
- **Entrega:** incremental — 3 fases, cada uma um PR testado
